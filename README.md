# 🍔 Responsive Hamburger Website

Modern ve kullanıcı dostu bir **hamburger restoran web sitesi**.
Bu proje **HTML, CSS ve JavaScript** kullanılarak geliştirilmiş **responsive (mobil uyumlu)** bir web sitesidir.

## 🚀 Proje Hakkında

Bu proje, bir restoran için hazırlanmış modern bir landing page tasarımıdır.
Site farklı ekran boyutlarına uyum sağlayacak şekilde **responsive** olarak tasarlanmıştır.


## ✨ Özellikler

* 📱 Tam **Responsive Tasarım**
* 🍔 Modern **Hamburger Restoran Teması**
* 🎨 Temiz ve düzenli **UI Tasarımı**
* ⚡ **JavaScript** ile etkileşimli yapı
* 🧭 Kolay ve kullanıcı dostu **navigasyon**
* 📝 Birden fazla sayfa yapısı

## 🛠️ Kullanılan Teknolojiler

* **HTML5**
* **CSS3**
* **JavaScript**

## 📂 Proje Klasör Yapısı

```
hamburger-website
│
├── images/        → Sitede kullanılan görseller ve demo GIF
├── scripts/       → JavaScript dosyaları
├── styles/        → CSS stil dosyaları
│
├── index.html     → Ana sayfa
├── about.html     → Hakkımızda sayfası
├── menu.html      → Menü sayfası
├── products.html  → Ürünler sayfası
├── blogs.html     → Blog sayfası
├── review.html    → Müşteri yorumları sayfası
├── conctact.html  → İletişim sayfası
│
└── README.md      → Proje hakkında bilgiler
```
